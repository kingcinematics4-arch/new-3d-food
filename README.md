# 🍔 3D Digital Food Menu & Restaurant Ordering SaaS

A multi-tenant **3D Food Menu & QR Tabletop Ordering SaaS** platform built with **Next.js 14 (App Router), React, TypeScript, Tailwind CSS, Three.js (@react-three/fiber), and Supabase**.

---

## ✨ Features Highlight

- **🏢 Multi-Tenant Hotel Architecture**: Each restaurant operates with isolated data, custom branding, and database Row Level Security (RLS) policies.
- **🍲 3D Food Model Inspector**: Interactive 360° GLTF/GLB 3D dish viewer powered by Three.js & R3F with Augmented Reality (AR) support.
- **📱 QR Code & Tabletop Standee Builder**: Single & batch QR code generation with custom color schemes and printable table standee frame templates.
- **🛒 Mobile-First Customer Digital Menu**: Diner menu with table detection (`?table=5`), category filters, dietary pills, 3D dish inspector modal, cart drawer, and order placement.
- **🔔 Kitchen Display System (KDS)**: Real-time live order stream for kitchen staff & waiters with status transitions (`Pending` ➔ `Cooking` ➔ `Ready` ➔ `Completed`).
- **📈 Revenue & Sales Analytics**: Interactive charts (ApexCharts) for sales volume, top 3D dishes, payment method split, and AOV boost metrics.
- **⭐ Customer Reviews & Ratings**: 5-star rating distribution and verified dish feedback system.
- **⚙️ Profile & Custom Domain Support**: Theme accent styling, logo URL, and Vercel custom domain configuration support.
